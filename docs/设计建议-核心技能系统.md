# 设计建议：XL Agent 核心技能系统 (Skills)

> 目标：将通用 AI Skills 转化为 XL Agent 的原生能力，实现从“对话”到“执行”的标准化。
> 核心理念：**不求多，只求精。只引入最符合 XL Agent “自进化”基因的 4 个核心技能。**

---

## 1. 任务澄清技能 (Clarification / Superpowers)
**作用**：在执行长任务或模糊需求前，强制进行目标对齐。

*   **XL Agent 实现**：
    *   在 `core.py` 的推理循环开始前，若检测到任务复杂度高（预期步骤 > 10），Agent 必须先输出一个 `[TASK SPEC]`。
    *   **协议**：包含：目标、成功标准、潜在风险、工具限制。
    *   **效果**：防止 Agent 在错误的方向上浪费 Token 和时间。

## 2. 方案构思技能 (Brainstorming)
**作用**：将一个想法转化为 2-3 个可行的技术路径。

*   **XL Agent 实现**：
    *   利用现有的 `spawn_agent`。
    *   **流程**：主 Agent 不直接动手，而是派发两个子代理（`architect` 角色）分别提供方案 A 和方案 B，主 Agent 负责对比并向用户汇报。
    *   **效果**：提升决策质量，避免单一路径的思维局限。

## 3. 技能沉淀技能 (Skill-Creator)
**作用**：将“操作流程”转化为“自动化工具”。

*   **XL Agent 实现**：
    *   **这是自进化的核心**。当 `on_session_end` 判定某个复杂操作（如：特定的代码部署流程）成功且重复时，自动生成 `.skill` 文件。
    *   **物化形式**：存放在 `agent/skills/` 下的 Markdown 文件，包含专用的 System Prompt。
    *   **效果**：实现“教一遍就会”，下次直接调用该技能。

## 4. 知识内化技能 (Knowledge / Obsidian)
**作用**：将本地 Obsidian 笔记转化为 Agent 的实时生产资料。

*   **XL Agent 实现**：
    *   **强化 `MemoryManager`**：目前的 `KNOWLEDGE_INDEX` 仅记录 Agent 产生的内容。
    *   **扩展**：允许 Agent 索引用户指定的 Obsidian 目录。
    *   **效果**：Agent 能直接引用你的学习笔记和项目文档进行推理。

## 5. 待引入工具增强

| 技能 | 推荐工具 | 引入理由 |
| :--- | :--- | :--- |
| **文件转换** | `markitdown` | 目前 `read_file` 只能读文本。引入该工具让 Agent 能读懂你放在目录下的 PDF 和 Word 文档。 |
| **自动化检查** | `playwright` | 当 Agent 编写了前端代码或部署了服务后，可以用它打开浏览器验证效果，而不是“盲写”。 |

## 实施建议

1.  **优先实装 `Skill-Creator`**：这是 XL Agent 与其他 Agent 最大的区别点，应配合 `implementation_plan.md` 优先落地。
2.  **强化 `Clarification` 意识**：通过修改 System Prompt，要求 Agent 在面对复杂任务时必须先输出计划清单。
