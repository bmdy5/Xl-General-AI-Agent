# DuoAgent — 圆桌讨论平台设计方案

## 功能分析

### 核心功能（第一阶段）

| 功能 | 说明 | 优先级 |
|------|------|:------:|
| 话题输入 | 用户输入想讨论的话题 | P0 |
| Agent 选择 | 从 6 个预设角色中勾选参与者（最少2个） | P0 |
| 轮次控制 | 滑块选择 1-6 轮 | P0 |
| 发起讨论 | 点击按钮开始，背景异步运行 | P0 |
| 实时消息流 | SSE 推送每位 Agent 的发言，逐条显示 | P0 |
| 发言状态 | 当前正在发言的 Agent 高亮+打字态 | P0 |
| Agent 标签 | 每条消息显示 Agent 名字+头像+颜色 | P0 |
| 系统消息 | 轮次切换、讨论开始/结束等状态提示 | P0 |
| 新讨论 | 结束后可重新开始 | P0 |

### 扩展功能（后续阶段）

| 功能 | 说明 |
|------|------|
| 用户插话 | 讨论过程中用户可打断并输入 |
| 导出记录 | 讨论结果导出 Markdown |
| 自定义角色 | 用户自定义 Agent 名称和人格 |
| 语音输出 | 每个 Agent 用不同 TTS 语音 |

## 设计风格

- **色调**: 暖色系 — 琥珀/金色渐变背景，白色毛玻璃卡片
- **圆角**: 大圆角（16px+），柔和过渡
- **字体**: 系统字体，无衬线
- **动效**: 消息出现时淡入上移，发言中头像跳动
- **Agent 标识**: 每个角色有独特表情符号+颜色
- **布局**: 固定宽度居中，上下留白

## 实现方式

1. 后端：FastAPI + SSE（已完成）
2. 前端：Stitch 生成 HTML/CSS
3. Agent：XL 的 LLM 客户端，每个角色带不同 persona
4. 接入：用户在浏览器打开，设置话题 → 开始 → 看讨论
