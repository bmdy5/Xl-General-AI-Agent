# 设计建议：像素风桌面伴侣 (XL Companion)

> **核心愿景**：为 XL Agent 打造一个具有“物理实体”的数字生命载体。它不仅是视觉装饰，更是 Agent 状态的实时播报器、技能的操作面板以及自进化的视觉呈现。

---

## 1. 技术架构总览

*   **UI 引擎**：Python + PyQt6 (支持置顶、透明、非规则窗口、鼠标穿透)。
*   **资产生成**：`image2_tool` (生成像素风序列帧)。
*   **视觉审计**：`Mimo` (利用 Vision 能力对生成的资产进行审美与逻辑审查)。
*   **通信协议**：Local Socket / WebSockets (Agent Core ⇄ UI Gateway ⇄ Desktop Pet)。

---

## 2. 进化路线图：四个阶段

### 第一阶段：身未动，意先行 (MVP 启动)
**目标**：建立 Agent 与桌面视觉的第一次连接。
*   **资产生成**：调用 `image2_tool` 预生成三张核心状态图：`idle.png` (待机)、`thinking.png` (思考)、`working.png` (执行)。
*   **视觉初审**：使用 Mimo 检查生成图是否符合“像素风”和“当前状态含义”。
*   **功能**：创建一个极简悬浮窗口，根据 Agent 状态（Idle/Think/Work）实时切换图片。

### 第二阶段：像素技能框 (The Skill Box)
**目标**：将 Agent 的后台能力通过 UI 显性化。
*   **交互逻辑**：点击宠物弹出“像素技能框”（复古 RPG 菜单风格）。
*   **状态展示**：
    *   **HP/MP 槽**：映射为 Token 消耗/上下文剩余空间。
    *   **动作图标**：展示当前正在调用的工具（如：放大镜=搜索，小锤子=写入）。
    *   **心流文字**：底部滚动展示 Agent 当前的思考摘要。
*   **远程控制**：点击技能框内的 Skills 按钮，可直接触发特定的子代理任务。

### 第三阶段：帧动画自进化 (Self-Review Animation)
**目标**：实现 Agent 的外形动态进化。
*   **资产流水线**：
    1.  Agent 自动构思一组动作（如：眨眼、翻书、打电脑）。
    2.  `image2_tool` 生成 4-8 帧的序列图。
    3.  Mimo 充当“动画导演”，审查帧与帧之间的连贯性。
*   **动态换肤**：UI 根据生成的资产动态更新动画，让宠物看起来是“活的”。

### 第四阶段：环境感知伴侣 (Autonomous Companion)
**目标**：让宠物真正“生活”在你的桌面上。
*   **智能跟随**：利用 `pygetwindow` 追踪当前活动窗口，宠物自动移动到窗口边缘。
*   **视觉反馈 (Mimo 联动)**：
    *   当你在写代码遇到 Bug 时，宠物头顶出现一个“？”气泡。
    *   当发现你长时间未操作，宠物进入“钓鱼/睡觉”状态。
*   **自进化规则物化**：每产生一条 `EVOLVED_RULES`，宠物的形象会解锁一件新装备。

## 3. 资产存储规范

```text

└── agent/
    └── companion/
        ├── ui.py              # PyQt6 窗口逻辑
        ├── gateway.py         # 状态推送网关
        └── assets/            # 自动生成的像素图
            ├── current/       # 正在使用的
            └── history/       # 进化历史备份
```

---

## 4. 立即开始的第一步

1.  **定义 Event Schema**：确定 `core.py` 每次状态变化时发送给 UI 的 JSON 格式。
2.  **生成第一代 Mascot**：指挥 Agent 产生它的“初始细胞”。
3.  **编写 `ui.py` 原型**：实现最基础的透明置顶显示功能。
