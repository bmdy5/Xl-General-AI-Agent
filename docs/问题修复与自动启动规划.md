## 1. DeepSeek 对话链条修复 (核心逻辑)

### 1.1 历史记录自动修护 (History Sanitizer)
*   **位置**：`agent/core.py` 中的 `_run_loop` 开始处。
*   **逻辑**：在调用 LLM 之前，检查 `self.messages`。如果最后一条（或几条）消息是 `assistant` 角色且包含 `tool_calls`，但后面没有紧跟对应的 `tool` 结果消息，则执行以下任一操作：
    *   **清理模式**：直接移除该条孤儿消息。
    *   **补全模式**：自动填充 `tool` 结果，内容为“执行中断/超时”。
*   **目标**：彻底根除 `insufficient tool messages` 报错，确保 Agent 在任何网络波动的下一轮都能秒恢复。

## 2. QQ 持久化与自动登录 (部署优化)

### 2.1 存储目录标准化
*   **修改点**：`启动QQAgent.command`。
*   **操作**：将挂载点从 `~/napcat-data-tmp` 改为 `~/.xlagent/napcat_data`。
*   **效果**：一次扫码，永久授权（除非 QQ 官方强制下线）。

### 2.2 NapCat 容器优化
*   **参数增加**：添加 `--restart always` 标志。
*   **逻辑控制**：优化脚本中的端口检测逻辑，缩短启动等待时间。

## 3. macOS 开机自动启动 (守护进程)

### 3.1 编写 `com.xlagent.qq.plist`
*   **存放路径**：`~/Library/LaunchAgents/com.xlagent.qq.plist`。
*   **执行任务**：开机自动执行 `启动QQAgent.command`。
*   **运行模式**：后台静默运行，日志输出至 `agent/auto_learn.log` 同级目录。
