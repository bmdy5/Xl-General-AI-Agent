# 自建 Agent：从零搭建通用 AI Agent

> 老肖 | 2026-05-09

目标：从零搭建一个自己的通用 Agent，能对话、能用工具、能上网、能记住事。**能复用优先复用，不重复造轮子。**

代码在：`agent工程学习/搭建agent/`

---

## 我有什么基础

在动手之前，我已经把 5 个开源 Agent 项目的代码和架构都分析过一遍了：

| 项目 | 语言 | 我的评价 |
|------|------|---------|
| tinypace | Python | 代码最清晰，BaseTool ABC 设计干净 |
| hermes | Python | ToolRegistry 单例模式好抄，但 run_agent.py 太大了 |
| cc-haha | TS/Bun | CC 原版逻辑，但 TS 我不太熟 |
| openclaw | TS | 插件体系最完整，但过度设计 |
| OpenMAIC | TS/Next.js | LangGraph 编排，适合多 Agent 场景 |

分析文档在 `Agent/` 下的各个子目录里，核心循环、工具系统、记忆系统、消息通道、多智能体设计都覆盖了。

---

## 原则

1. **能复用优先复用** — 5 个项目里能直接抄的绝不自己写
2. **简单优先** — Anthropic 自己说的，能单次 LLM 调用的就不要上 Agent，能 Workflow 的就不要上多 Agent
3. **每阶段可独立验证** — 做完一个阶段，跑通了，再搞下一个
4. **Python + LiteLLM** — Python 我熟，LiteLLM 统一多 provider 接口

---

## 实操路线

```
阶段 1: Hello Agent        ✅ 已完成  → 对话、读文件、写文件、执行命令
阶段 2: 工具系统            ✅ 已完成  → web_search + web_fetch，能上网
阶段 3: 上下文压缩          ✅ 已完成  → 75%阈值 + 熔断器，长对话不爆
阶段 4: 自动记忆            ✅ 已完成  → 5类记忆 + 禁止清单 + 时间戳进化
阶段 5: 注入模式升级        ✅ 已完成  → 静态/动态分离 + [MEMORY BLOCK] + Periodic Nudge
阶段 6: 自主学习系统        ✅ 已完成  → flash提取 + pro审查 + 知识库 + 技能创建
阶段 7: 接入外部服务        🔜 待设计   → Image2 等外部 API
```

## 代码文件对照

写完后的项目结构：

```
搭建agent/
├── main.py                  # CLI 入口
├── run.sh                   # 启动脚本
├── requirements.txt
├── .env / .env.example
├── docs/                    # 技术设计文档（给 AI 看的）
│   ├── 升级路线总览.md
│   ├── 升级设计-阶段2-工具系统.md
│   ├── 升级设计-阶段3-上下文压缩.md
│   └── 升级设计-阶段4-自动记忆.md
└── agent/
    ├── core.py              # 🔥 核心循环
    ├── llm.py               # LiteLLM 封装
    ├── compressor.py        # 上下文压缩（阶段3）
    ├── tools/
    │   ├── base_tool.py     # 抄自 tinypace
    │   ├── registry.py      # 简化自 hermes
    │   ├── file_tools.py    # read_file, write_file
    │   ├── bash_tool.py     # shell 执行
    │   ├── web_search_tool.py  # 网络搜索（阶段2）
    │   └── memory_tool.py   # 自动记忆（阶段4）
    ├── session/
    │   └── handler.py       # JSONL + fsync（阶段1）
    └── memory/
        └── manager.py       # MEMORY.md 管理（阶段1）
```
