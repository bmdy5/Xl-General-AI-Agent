# 阶段 8：自主学习系统

> 老肖 | 2026-05-09

目标：agent 每天自动浏览网页学习 10 分钟，知识存入知识库，高质量知识进入长期记忆。

---

## 1. 系统架构

```
每天 10:00 自动触发（launchd）
  │
  ▼
flash 模型快速提取（deepseek-v4-flash，省钱）
  web_search → web_fetch → LLM 分析（摘要/分类/技能初评）
  │
  ▼
pro 模型审查（deepseek-v4-pro，保证质量）
  审查标准：通用性、可操作性、准确性、是否重复
  │
  ├── ✅ 通过 → 存知识文件 + agent 记忆 + 创建技能（评分≥7）
  └── ❌ 不通过 → 只存知识文件，不污染记忆
```

## 2. 三道滤网

| 滤网 | 模型 | 做什么 |
|------|------|--------|
| **粗筛** | flash | 搜索 + 读文章 + 初步提取 |
| **精审** | pro | 判断通用性、可操作性、准确性 |
| **去重** | 代码 | URL 去重 + 技能同名检测 |

## 3. 知识输出

```
agent自主学习的东西/
├── 每日摘要-2026-05-09.md
├── AI/           ← LLM/Agent/Prompt 相关
├── 后端/         ← Python/FastAPI/数据库相关
├── 前端/         ← React/TypeScript/CSS 相关
├── 运维/         ← Docker/K8s/CI/CD 相关
└── 技能/         ← agent 自建的技能文件
```

## 4. 使用方法

```bash
# 手动学习
./auto_learn.sh

# 知识库清理（删重复、去小众、合并同类）
python main.py --cleanup

# 安装定时任务（每天 10:00）
cp com.myagent.autolearn.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.myagent.autolearn.plist
```

## 5. Token 成本

| 步骤 | 模型 | 每次消耗 |
|------|------|---------|
| 搜索+抓取 | 无 | 0 token |
| 文章分析 | flash | ~1K token/篇 |
| 审查 | pro | ~500 token/篇 |
| **10 分钟约读 6 篇** | | **~9K token** |
