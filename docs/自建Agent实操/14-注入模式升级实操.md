# 阶段 7：注入模式升级

> 老肖 | 2026-05-09

目标：记忆不只是"存了什么"，更重要的是"何时注入、注入哪里、注入多少"。

---

## 1. 改了什么

### 1.1 静态/动态 prompt 分离（抄 CC）

```
之前：一整坨 prompt，每次全量重算
  system_prompt = STATIC_PROMPT

现在：静态段 + cache boundary + 动态段
  system_prompt = 静态段（身份/规则/工具/禁止清单）
                  ── cache boundary ──
                  动态段（时间/cwd/记忆索引）
```

**效果**：静态段可以缓存（如果 provider 支持），省钱。动态段每轮重算，记忆变化立刻生效。

### 1.2 [MEMORY BLOCK] 每轮 prefetch（抄 hermes）

```
之前：记忆只在启动时注入 system prompt
  启动 → load_context() → 拼到 system prompt 后面 → 一整坨

现在：首轮注入 [MEMORY BLOCK] + 后续 Periodic Nudge
  首轮：[MEMORY BLOCK] 包含最新 8 条记忆，注入到消息列表
  每10轮：Periodic Nudge 提醒 agent 检查记忆
```

**注入位置**：消息列表中的 system 消息（不是 system prompt）

```
llm_messages = [
  {"role": "system", "content": system_prompt},     ← 静态+动态
  {"role": "system", "content": [MEMORY BLOCK]},    ← 记忆隔离块
  ...conversation messages...
]
```

### 1.3 注入上限（抄 openclaw）

```
[MEMORY BLOCK] 最多 4000 字符
记忆索引最多 8 条
MEMORY.md 最多 25KB
```

### 1.4 Periodic Nudge（抄 hermes）

```
每 10 轮 → yield {"type": "nudge"}
→ [MEMORY BLOCK] 注入提醒："有没有值得长期记住的？"
```

---

## 3. 对比：改前 vs 改后

| 维度 | 改前 | 改后 |
|------|------|------|
| System prompt | 一整坨 | 静态段 + 动态段（cache boundary） |
| 记忆注入时机 | 仅启动时 | 首轮 + 每 10 轮 Nudge |
| 记忆注入位置 | system prompt 尾部 | [MEMORY BLOCK] 独立系统消息 |
| 记忆注入量 | 全量 | 最新 8 条 / 4000 字符上限 |
| 隔离标签 | 无 | [MEMORY BLOCK]...[/MEMORY BLOCK] |
| 缓存 | 无 | 静态段可缓存 |
