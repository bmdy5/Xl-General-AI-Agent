## 2. 三家完整对比

### CC 的进化体系

```
写入层：Auto Memory（5类记忆+禁止清单）
       Session Memory（自然断点摘要）
       Agent Memory（每个子agent的专属记忆）

创建层：skill-creator 元技能
       Claudeception 自动转化经验为Skill
       自然语言描述直接生成Skill

注入层：构造时固定到 system prompt
       轻量模型从 MEMORY.md 选最多5个文件
       25KB/200行上限
```

### openclaw 的进化体系

```
写入层：Active Memory（active-memory 插件）
         ├── memory_search：搜索历史
         ├── memory_recall：召回相关上下文
         └── 6种 prompt 风格（含 preference-only 专门召回偏好）
       
       钩子捕获：
         ├── after_tool_call：每个工具调用后审计
         ├── on_session_end：全局总结
         └── on_turn_end：每轮结束

创建层：skill-creator 技能
         ├── create：创建新技能
         ├── edit：编辑已有技能
         └── improve：改进已有技能 ← 这是 CC 没有的

注入层：工作区文件预加载（USER.md/SOUL.md/AGENTS.md）
       强制召回步骤（Mandatory recall step）
       BM25+向量混合检索
       4000字符注入上限+熔断器
```

### hermes 的进化体系

```
写入层：prefetch 每轮检索
       sync_turn 每轮同步
       on_session_end 全局总结

创建层：自主 Skill 创建（agent 自己决定）
       Skill 自我改进（v1→v1.1→v2 闭环）
       Periodic Nudges（主动推动学习）

注入层：[MEMORY BLOCK] 标签隔离
       Provider 可插拔后端
       1内置+1外部限制
```

---

## 3. 关键差异：不是"有没有"，是"怎么做到的"

| 能力 | CC | openclaw | hermes |
|------|-----|----------|--------|
| **记住偏好** | Auto Memory 5类分类 | Active Memory preference-only 模式 | prefetch + sync_turn |
| **捕获反馈** | Session Memory 自然断点 | after_tool_call + on_session_end 钩子 | sync_turn |
| **创建技能** | 自然语言 + skill-creator + Claudeception | skill-creator（create/edit/improve） | 自主创建 |
| **改进技能** | ❌ | ✅ skill-creator improve 模式 | ✅ 自我改进循环 |
| **跨会话搜索** | 轻量模型选文件（最多5个） | BM25+向量混合+熔断器 | FTS5全文+LLM摘要 |
| **防遗忘** | ❌ 无强制机制 | ✅ Mandatory recall step | 🔸 每轮 prefetch |
| **搜索防爆** | 25KB/200行上限 | 4000字符+熔断器 | 1内置+1外部限制 |
| **自主学习** | 🔸 Claudeception 自动转化 | ❌ 需用户触发 skill-creator | ✅ Agent 主动决定 |

## 4. 最终结论：给你的 agent 的组合方案

取每家最强的：

```
┌─────────────────────────────────────────────────┐
│              我的 Agent 进化系统                   │
├─────────────────────────────────────────────────┤
│                                                  │
│  记忆分类 ← 抄 CC                                 │
│  ├── 5类记忆：user/feedback/project/reference/learn│
│  └── 禁止清单：不记代码结构/git历史/已有文档/临时任务  │
│                                                  │
│  反馈捕获 ← 抄 openclaw                            │
│  ├── after_tool_call 钩子：每次工具执行后审计        │
│  ├── on_session_end 钩子：全局总结                 │
│  └── 自然断点检测（抄CC）：不在工具链中间截断          │
│                                                  │
│  技能创建 ← 抄 CC + openclaw                       │
│  ├── 自然语言说需求 → 自动生成（CC）                  │
│  ├── skill-creator 指导创建/验证/打包（两家都有）      │
│  └── improve 模式：改进已有技能（openclaw）          │
│                                                  │
│  自主学习 ← 抄 hermes（这个三家只有 hermes 有）       │
│  ├── Agent 主动决定"这个值得学"                      │
│  ├── 完成复杂任务后自己创建 Skill                     │
│  └── Skill 在使用中自我改进 v1→v1.1→v2              │
│                                                  │
│  检索注入 ← 抄 openclaw                            │
│  ├── 强制召回步骤：工具描述里写 Mandatory recall       │
│  ├── 简单 BM25 关键词匹配（先不做向量）               │
│  └── 注入上限 + 熔断器                              │
│                                                  │
│  存储 ← 抄 CC                                     │
│  └── Markdown + MEMORY.md 索引，零依赖              │
│                                                  │
└─────────────────────────────────────────────────┘
```

## 5. 落地优先级

```
第1步：记忆 + 反馈捕获（CC + openclaw）
  → save_memory 工具 + 5类分类 + 禁止清单
  → after_tool_call 审计
  → 效果：agent 能正确记住偏好和反馈

第2步：技能创建 + 改进（CC + openclaw + hermes）
  → 自然语言创建技能（抄CC）
  → skill improve 模式（抄openclaw）
  → 自主学习闭环（抄hermes）
  → 效果：agent 能自己创建技能、改进技能

第3步：检索升级（openclaw）
  → 强制召回步骤
  → BM25 关键词匹配
  → 熔断器
  → 效果：过去的反馈永远不会被遗忘
```
