# 像素办公室 Dashboard v2 设计方案

> 分支: feature/pixel-office-v2 | 日期: 2026-05-10

## 目标

将现有的 `fillRect` 色块风格 Dashboard 升级为《星露谷物语》风格的精细像素画办公室，保持 SSE 实时通信架构不变，仅升级前端渲染层。

---

## 架构

```
浏览器 (Canvas) ←─SSE── Python HTTP Server ←── Agent 事件流
     │                    │
agent/dashboard_v2/    agent/dashboard.py (复用，不改动)
├── index.html
├── engine.js      # 瓦片渲染引擎
├── sprites.js     # 精灵管理 + 动画状态机
├── events.js      # SSE 事件处理 + Agent 状态
└── assets/
    ├── tiles.png       # 地板/墙/门 瓦片图集
    ├── furniture.png   # 家具图集
    └── agents.png      # 角色精灵（含行走 4 帧）
```

后端仅需修改 `dashboard.py` 的 `HTML_PATH` 指向 `dashboard_v2/index.html`。

---

## 视觉标准

参考《星露谷物语》室内场景：
- 瓦片尺寸：16×16 像素（Canvas 放大 3x = 显示 48×48）
- 地图大小：40×26 瓦片（1920×1248 逻辑像素，viewport 内滚动）
- 角色精灵：16×32（站立）+ 4 帧行走动画

## Agent 交互

- **点击 Agent**：弹出像素风详情 Panel
- **Panel 内容**：名称、角色、Token 进度条（伪血条）、记忆数量、当前状态
- **动画状态机**：`idle → walk → action → idle`
- **行走**：lerp 插值移动，每 8 帧切换左右脚

---

## 分阶段实施

| 阶段 | 内容 | 完成标志 |
|---|---|---|
| **P1** | 文件结构 + 瓦片地图系统 | 可见有纹理的地板和房间轮廓 |
| **P2** | 家具精灵渲染 | 桌椅、书架、电脑出现在正确位置 |
| **P3** | 角色精灵 + 行走动画 | Agent 在房间里平滑移动 |
| **P4** | 点击交互 + 属性 Panel | 点 Agent 弹出像素风详情框 |
| **P5** | SSE 接入 | 接收真实 Agent 事件，触发移动/气泡 |

---

## 复用策略

- `dashboard.py`：**完全不改**，只改 HTML_PATH
- SSE 事件协议：**不变**，前端 events.js 兼容现有 JSON 格式
- `start_dashboard.sh`：修改路径指向 v2
