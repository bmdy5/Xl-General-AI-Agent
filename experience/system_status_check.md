# 系统状态巡检与防冲突

## 巡检步骤

1. **基础状态检查**
   - 检查CPU、内存、磁盘空间、网络连通性等关键指标。
   - 输出简易健康度（正常/警告/异常）。
2. **日志归集巡检**
   - 检查最近日志文件（如`/var/log/`或项目专用日志）是否有ERROR、CRITICAL级别报错。
   - 确认日志服务（如rsyslog、systemd-journal）正常运行。
3. **QQ网关防双进程冲突**
   - 运行命令 `ps aux | grep -c qq-gateway` 或等效方式检查QQ网关进程数量。
   - 若进程数 > 1，则保留第一个进程，强制结束其余进程（`kill -9 <PID>`），并记录事件。
   - 若进程数为0，则尝试重启QQ网关服务并告警。
4. **自愈保障**
   - 对发现的异常（服务宕机、磁盘满等）自动尝试恢复（如重启服务、清理临时文件）。
   - 若自愈失败，输出详细告警信息并通知管理员。
5. **记忆连贯性确认**
   - 对比上次巡检报告，标记新增或消失的异常项。
6. **输出报告**
   - 整理为结构化状态报告，包含巡检时间、各项状态、自愈动作及结果。
