# 内容补全与二次检查流程

## 触发
待补全|二次检查|整体扫一遍|审查代码|获取修改信息|语法检查|查阅日志与搜索关键信息|对照规范与设计文档

## 步骤
1. 识别待补全或遗留项
2. 执行补全操作（修改文件）
3. 添加或更新自查规则
4. 查看文件内容，搜索关键词或函数定义，阅读和分析代码逻辑
5. 进行语法检查以确保代码的语法正确性
6. 查阅日志与搜索关键信息以了解系统状态
7. 对照规范与设计文档确认实现是否一致
8. 整体扫描文件进行二次检查
9. 发现并清理残留/错误
10. 获取最近修改的信息，包括代码变更和日志变化
11. 进行语法检查以确保改动无误
12. 结合日志时间变化进行分析
13. 综合分析并给出结论
