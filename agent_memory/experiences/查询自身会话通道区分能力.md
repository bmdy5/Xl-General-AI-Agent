# 查询自身会话通道区分能力

## 触发
你知道你当前是在...吗|你能区分...吗

## 步骤
1. 用户提问自身是否知道所在会话通道或能否区分不同通道
2. agent通过grep搜索代码中session_key、channel、私聊/群聊等关键词
3. agent根据搜索结果回答通道区分规则
