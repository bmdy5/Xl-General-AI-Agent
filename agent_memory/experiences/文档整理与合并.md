# 文档整理与合并

## 触发
整理、合并、汇总、笔记、整理文档、整合目录、合并笔记

## 步骤
1. **扫描目录结构与文件列表**  
   遍历当前目录及所有子目录，统计文件分布，对文件（可指定类型）按名称排序并记录路径。此步骤同时适用于复杂整理与简单合并场景。

2. **读取文件内容或统计信息**  
   根据需求读取文件全文、摘要或统计行数。对于简单合并，直接读取所有目标文件完整内容；对于复杂整理，可先提取关键信息供后续分析。

3. **分析内容并制定整理方案**  
   评估文件间的重复、冗余、层级关系，提出具体方案：合并相似文件、删除无用内容、打平子目录或重写结构。若仅需简单合并（如将所有笔记内容写入一个新文件），则直接进入下一步，跳过分析中的冗余判断。

4. **执行方案并清理冗余**  
   按方案执行合并、移动、删除等操作。对于简单合并，将所有读取内容顺序写入一个新文件（可自动命名或指定）；对于复杂整理，同步更新目录结构，移除临时或空文件，确保整理结果整洁一致。
