# 技术方案对比表格生成

## 触发
- 用户提出多个技术方案的比较分析需求
- 用户直接表达“写对比文档”、“对比”、“合并”、“写合并版”、“看看这个工具”或“你需要哪些”等类似指令
- 涉及工具选型、框架评估、技术栈对比等场景

## 步骤
1. **获取信息来源**  
   根据对比主题，执行以下操作以获取必要数据：
   - 访问指定 URL，读取相关文档或页面内容
   - 搜索相关工具的社区与生态数据（如 Star 数、活跃度、插件生态等）
   - 读取自身能力文档，了解本引擎已具备的功能边界与限制

2. **识别并读取源文件**  
   定位并读取所有相关的技术方案源文件（包括外部获取的信息、用户提供的文档、项目内已有文件等）。

3. **逐项对比分析各维度**  
   明确对比维度（如性能、复杂度、适用场景、成本、社区活跃度、功能完备性等），逐一分析每个方案在各维度上的表现，并标记最佳选项（可加粗或用“★”注明）。若涉及本引擎自身能力，需标注兼容性或优劣势。

4. **构建对比表格**  
   将分析结果整理为结构清晰的表格，确保每一维度、每一方案的对比一目了然。表格可使用 Markdown 格式，必要时添加备注列。

5. **输出表格并附带简要结论**  
   以可读格式（如 Markdown）输出表格，并总结推荐方案或权衡建议。

6. **合并写入一个文件**  
   将对比表格、结论及所有相关原始记录（如外部数据摘要、自身能力文档引用）合并写入一份完整文档，保存至指定路径。

7. **更新 index 文件**  
   将新生成的文档链接或索引添加至项目目录索引文件中。

8. **查看目录确认**  
   检查目录结构，确保文档被正确收录，可快速定位。
