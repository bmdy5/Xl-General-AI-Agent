# 命令报错自愈

## 触发
bash 命令返回非零退出码或明显的报错信息

## 步骤
1. 先读报错信息判断根因类型：语法问题 / 平台差异 / 路径错误 / 命令不存在
2. 如果是 macOS/Linux 平台差异（如 grep -P 不支持、find 参数不同），主动切换为通用兼容写法
3. 如果是 glob 语法问题（如 **/ 在双引号内不展开），拆成 find 或改用单引号
4. 同一命令连续两次报错，必须先停下来查 man 或 --help，不能第三次盲试
5. 如果是 command not found，检查环境变量或路径，考虑用 npx/pip 安装
6. 不走"闷头瞎改参数再试"路线，每次修改必须有根因分析依据
