# 浏览器视觉点击

## 触发
截图点击、刷视频、发评论、点击私信、看视频、点进去、点击视频、评论、在知乎发评论

## 步骤
1. 连接浏览器网关（端口3020）
2. 获取当前页面截图或分析 DOM 元素结构
3. 根据触发场景定位目标：
   - **截图点击**：获取指定坐标
   - **文本/标题/链接点击**：解析 DOM 定位对应元素
   - **评论操作**（通用流程，支持多平台适配，含知乎专有优化）：
     a. 打开目标页面（如小红书笔记详情页、知乎回答/文章页等）
     b. 定位并点击评论按钮（或评论区展开按钮）
     c. 等待评论区展开，定位评论输入框（可能为 `textarea` 或 `contenteditable` 元素）
     d. 输入评论内容：
        - 优先采用直接设置 `value` / `innerText` 并触发 `input` 事件（高效，适用于 contenteditable 输入框）
        - 若失败或平台需要模拟人工输入，则使用键盘逐字输入，并模拟合理输入节奏
     e. 点击发布/提交按钮
     f. 检查发布成功状态（确认按钮消失、出现成功提示或页面变化）
4. 执行点击操作（坐标或元素）
5. 等待必要的页面响应（如页面跳转、弹窗出现）
6. 截图确认当前状态并反馈操作结果
