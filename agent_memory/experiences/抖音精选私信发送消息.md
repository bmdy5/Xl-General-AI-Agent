# 抖音精选私信发送消息

## 触发
需要向抖音用户发送私信

## 步骤
1. 打开抖音网页版。
2. 定位私信图标：通过DOM分析或视觉识别确定其所在位置，然后使用坐标或选择器点击该图标。
3. 在弹出的联系人列表中，找到并点击目标用户。
4. 在聊天窗口的输入框中，填写要发送的消息内容。
5. 按回车键或点击发送按钮完成发送。
6. （可选）截图确认发送成功。
