# 简历内容修改与反馈

## 触发
用户提出修改简历某部分内容或项目描述，或要求保留/删除特定内容。常见表达如“改两句话”“多一点”“要改”，或直接提供文本片段请求修改建议。

## 步骤
1. **解析用户请求**：明确用户意图（增、删、改、润色、压缩、重写、保留、对比等）；若用户直接提供文本片段，则跳过此步骤直接进入分析。
2. **获取待修改文本**：如需修改，从相关文件或历史记录中查找原文；若已提供片段，则直接使用。
3. **分析内容**：通读原文或片段，识别冗余、表述不清、可优化之处（如重复、不够简练、缺少量化成果、时态不一致等）。
4. **提供修改选项**：给出多个方案供用户选择，包括但不限于：
   - **保留**：维持原样，不修改。
   - **压缩**：精简表达，保留核心信息。
   - **润色**：优化措辞，提升专业性。
   - **重写**：用全新方式表述。
   - **对比**：并列展示原版与各修改版，突出差异。
   每个选项附带简要说明（如突出什么特点、适用场景）。
5. **根据反馈调整**：听取用户选择或进一步要求（如“再压缩一点”“加回某部分”），迭代修改直至用户满意。
6. **输出最终结果**：呈现确认后的修改版本，并总结各选项的优缺点，便于用户决策。
