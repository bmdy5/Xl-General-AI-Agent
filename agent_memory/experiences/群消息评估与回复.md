# 群消息评估与回复

## 触发
- 用户明确要求查看群内特定成员的消息并评估回复
- 用户使用触发词：查看群里、看一下、回他一下、查看群聊消息、看看群里面、跟他聊聊、去@她问一下、再@她问一下、去问他、你去问、群里发消息、去群里、@他、发消息等相似指令
- 用户直接提及群内某人讨论内容并要求助手介入
- 用户要求助手在群内@某人并提问（可连续进行）

## 步骤
1. 检查群消息记录文件是否存在，若不存在则提示用户尚无记录，终止流程；否则继续。
2. 接收用户指令，解析目标对象、消息内容或询问意图：
   - 若提及具体成员，识别其QQ号/群聊身份；
   - 若未提及，则读取最新群消息内容。
3. 分析用户意图与消息内容：
   - 判断是否需要主动向某成员提问（如“去问他”、“去@他问一下”）、回复群聊、仅整理输出，或进行连续提问。
4. 根据分析结果执行：
   - **主动提问**：构造包含上下文与问题内容的私信或群内@消息，发送后等待回复并反馈用户，然后询问用户是否继续提出下一个问题（若有则重复本步骤）。
   - **回复群聊**：生成恰当回复内容并发送到群（可包含询问、讨论或直接回应）。
   - **整理输出**：输出简洁摘要或关键点给用户。
5. 若用户继续指示下一个问题，返回步骤2（定位目标），重复执行直至用户终止。
