# 代码变更与提交查询

## 触发
- 缓存功能或 git 修改（如 `git diff` 变更的文件）
- 用户直接发起「审查提交」「查看代码变更」「查看提交历史」「作者贡献」等请求

## 步骤
1. 进入项目目录
2. 根据用户意图，执行以下分支之一：
   - **查看未提交的变更**（默认）
     - 执行 `git diff HEAD --name-only`，列出所有修改的文件
     - 根据用户关键词，选择性执行：
       - 使用 `grep` 在文件内容中搜索
       - 使用 `find` 按文件名查找
       - 查看 `git log` 中相关的提交记录
     - 对用户指定的文件，执行 `git diff HEAD -- <文件路径>`，并自动限制输出行数（如 `| head -100`）
     - 如有多个文件，依次重复上一步，逐一展示差异
     - 汇总分析结果，清晰呈现给用户
   - **查看提交历史**（用户提及「历史」「提交记录」「作者」「贡献」等）
     - 统计提交次数：`git log --oneline | wc -l`
     - 列出详细提交：`git log --all --format`
     - 提取所有作者信息：`git log --format='%an <%ae>' | sort -u`
     - 根据用户指定作者，查询该作者的提交：`git log --author="<作者名>"`
     - 若用户需要结合文件过滤，可组合 `-- <文件路径>` 或 `--grep` 等参数
     - 输出结果并简要汇总

## 示例
- 用户说“看看最近改了哪些文件”→ 执行分支1，列出修改文件
- 用户说“查看 src/index.js 的变更”→ 执行分支1，限制行数输出差异
- 用户说“审查所有修改的文件”→ 执行分支1，依次显示每个文件的差异
- 用户说“这个项目有多少次提交”→ 执行分支2，统计并展示
- 用户说“查看所有提交历史”→ 执行分支2，列出详细提交
- 用户说“看看张三的贡献”→ 执行分支2，按作者过滤提交
